# Structured Commit Examples

## Correct ✅
- `feat(api): implement users endpoint` (31 characters)
- `fix(auth): correct memory leak in login` (32 characters)
- `docs(readme): update installation guide` (33 characters)
- `refactor(db): simplify database connection` (36 characters)

## Incorrect ❌
- `feat: added new push notification system for mobile` (Too long)
- `fixed login error` (Too informal and missing type)
- `fix: bug` (Description is not descriptive)
